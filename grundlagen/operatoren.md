# Operatoren und Anforderungsbereiche (Mathematik NRW)

Aufgabenstellungen beginnen immer mit einem Operator. Die Zuordnung zu einem Anforderungsbereich
hängt immer von der konkreten Aufgabe ab – die Liste zeigt die **typische** Zuordnung.

## AFB I – Reproduzieren
Grundwissen wiedergeben, Routineverfahren in bekanntem Zusammenhang ausführen.

| Operator | Bedeutung |
|---|---|
| angeben, nennen | Ergebnis/Begriff ohne Begründung und Lösungsweg formulieren |
| berechnen | Ergebnis von einem Ansatz ausgehend durch Rechenoperationen gewinnen |
| bestimmen, ermitteln (Routine) | Zusammenhang oder Lösungsweg aufzeigen und Ergebnis formulieren |
| zeichnen, darstellen | maßstäblich genaue Darstellung / sachgerechte Wiedergabe |
| skizzieren | wesentliche Eigenschaften grafisch übersichtlich darstellen |
| vereinfachen | Term mithilfe von Regeln in eine einfachere Form bringen |
| lösen | Gleichung bzw. Problem mit bekanntem Verfahren lösen |

## AFB II – Zusammenhänge herstellen
Bekanntes selbstständig auswählen, anordnen und in neuen, aber vergleichbaren Situationen anwenden.

| Operator | Bedeutung |
|---|---|
| erläutern | Sachverhalt mit Beispielen/zusätzlichen Informationen verständlich machen |
| erklären | Sachverhalt auf Regeln, Gesetze, Zusammenhänge zurückführen |
| begründen | Sachverhalt auf Regeln und Gesetzmäßigkeiten bzw. kausale Beziehungen zurückführen |
| vergleichen | Gemeinsamkeiten und Unterschiede herausarbeiten |
| interpretieren, deuten | Ergebnisse auf die Ausgangssituation beziehen |
| untersuchen | Eigenschaften/Beziehungen mit fachlichen Kriterien herausfinden |
| zeigen, nachweisen | Aussage mit gültigen Schlussregeln bestätigen |
| zuordnen | Begriffe/Darstellungen begründet einander zuordnen |
| überprüfen | Aussage/Ergebnis an Fakten oder innerer Logik messen |

## AFB III – Verallgemeinern und Reflektieren
Komplexe Problemstellungen selbstständig bearbeiten, eigene Wege entwickeln, beurteilen.

| Operator | Bedeutung |
|---|---|
| beurteilen | zu einem Sachverhalt ein selbstständiges Urteil mit Fachwissen begründet formulieren |
| bewerten | Sachverhalt an Kriterien messen und Werturteil begründen |
| beweisen | Aussage über eine Kette gültiger Schlüsse aus Voraussetzungen herleiten |
| entwickeln | Lösungsweg/Modell/Idee selbstständig erarbeiten |
| verallgemeinern | aus Einzelfällen eine allgemeine Aussage gewinnen und begründen |
| widerlegen | Gegenbeispiel finden oder Widerspruch aufzeigen |
| Stellung nehmen | begründete eigene Position zu einer Aussage formulieren |

## Verteilung in Klassenarbeiten (Fachschaftsvorgabe)

**AFB I: 30 % · AFB II: 50 % · AFB III: 20 %** der Gesamtpunkte (Toleranz ±3 Prozentpunkte).
