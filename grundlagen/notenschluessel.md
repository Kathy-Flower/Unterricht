# Notenschlüssel (Fachschaft Mathematik)

## Klassenarbeiten (verbindlich)

| ab % der Punkte | Note |
|---|---|
| 90 % | sehr gut (1) |
| 75 % | gut (2) |
| 60 % | befriedigend (3) |
| 45 % | ausreichend (4) |
| 20 % | mangelhaft (5) |
| 0 % | ungenügend (6) |

Im Erwartungshorizont immer eine Punkte-Tabelle mitliefern: Punktgrenzen je Note, berechnet als
`aufrunden(Prozent × Gesamtpunkte)` auf halbe Punkte.

## Feinabstufung mit Tendenzen (Übungswebsites, ggf. Klassenarbeiten)

Jede Notenstufe wird in drei gleich große Teile geteilt (unteres Drittel = −, oberes Drittel = +).
**Diese Abstufung ist eine Annahme** – ändern, falls die Fachschaft andere Grenzen hat.

| 85 | 2+ | 80 | 2 | 75 | 2− |
| 70 | 3+ | 65 | 3 | 60 | 3− |
| 55 | 4+ | 50 | 4 | 45 | 4− |
